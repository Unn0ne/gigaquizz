# Gigaquizz

Сервис опросов на Go и PostgreSQL. Организатор создаёт вопрос и делится ссылкой, участники голосуют без регистрации, а результаты доступны в защищённом кабинете.

- Один активный опрос, длительность — ровно 60 секунд.
- Один или несколько вариантов ответа; свободного текста нет.
- Базовая защита от повторов по случайному ID браузера для каждого опроса.
- Первый принятый выбор окончательный.

Для локального запуска нужны **Go 1.26.1+, Python 3, make** и **PostgreSQL 16+ либо Docker Compose**:

```sh
git clone https://github.com/Unn0ne/gigaquizz.git
cd gigaquizz
make dev
```

Скрипт подготовит БД и при первом запуске создаст `.env` со случайным паролем администратора.

Откройте `/admin` по адресу `PUBLIC_URL` из `.env` — по умолчанию **http://127.0.0.1:8080/admin**. Пароль указан в `ADMIN_PASSWORD`. Создайте опрос в кабинете и скопируйте ссылку для участников. Остановка приложения — Ctrl+C.

Сборка: `make build`. Проверки кода и тесты: `make check`.

Рабочий сайт использует PostgreSQL. Отдельный файловый стенд на Go проверяет приём **100 млн голосов за минуту** без Kafka и БД. Его ещё нужно подключить к HTTP и кабинету; измерения ядра не означают готовность всего сайта к такой нагрузке.
