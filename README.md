# Gigaquizz — Go и файлы

Ветка `simple-files`: полный сервис опросов с сайтом и защищённым кабинетом. PostgreSQL и Kafka не нужны; данные сохраняются на локальном диске.

- Один активный опрос длится ровно 60 секунд.
- Ответы — выбор одного или нескольких вариантов.
- Случайный ID браузера защищает от обычных повторов; учитывается первый сохранённый выбор.
- Ответ сервера подтверждает запись на диск. Итоги рассчитываются после закрытия.

Нужны **Go 1.26.1+, Python 3 и make**, macOS или Linux:

```sh
git clone --branch simple-files https://github.com/Unn0ne/gigaquizz.git
cd gigaquizz
make dev
```

Откройте **http://127.0.0.1:8091/admin**. Пароль администратора находится в созданном `.env.simple-files`. При существующем `.env.simple-files` адрес определяется его `PUBLIC_URL`.

Данные находятся в `DATA_DIR` (по умолчанию `.local/files`). Сохраняйте весь каталог для перезапуска и резервного копирования. Одновременно его открывает один процесс.

Проверки: `make check`. Сборка: `make build`. Браузерные проверки и установка браузера — в [инструкции](docs/branch-verification.md).
