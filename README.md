# Gigaquizz

Опросы на одну минуту. Вы создаёте вопрос и отправляете ссылку, участники выбирают ответ без регистрации, а после закрытия вы смотрите результаты в кабинете.

Можно выбрать один или несколько вариантов. Голосование длится ровно 60 секунд. При обычном повторном заходе из того же браузера учитывается первый сохранённый ответ.

Это ветка **postgres-kafka**: Kafka сохраняет ответы, PostgreSQL — вопросы и готовые результаты. Версия, которой достаточно Go и файлов, находится в [ветке simple-files](https://github.com/Unn0ne/gigaquizz/tree/simple-files).

Для локального запуска нужны **Go 1.26.1+, Python 3.11.4+, make, Java 21+**, а также **PostgreSQL 16+ или Docker Compose**:

```sh
git clone --branch postgres-kafka https://github.com/Unn0ne/gigaquizz.git
cd gigaquizz
make kafka-up
make dev
```

`make kafka-up` подготовит локальную Kafka из трёх брокеров. `make dev` подготовит PostgreSQL и запустит приложение.

Откройте **http://127.0.0.1:8092/admin**. Пароль — строка `ADMIN_PASSWORD` в созданном файле `.env.postgres-kafka`. В кабинете создайте опрос и скопируйте ссылку для участников. При старте «сейчас» сначала идут 20 секунд подготовки, затем минута голосования.

Если PostgreSQL и Kafka уже работают, заполните `.env.postgres-kafka` по примеру `.env.example` и выполните `make run`. [Подключения, остановка и восстановление](docs/postgres-kafka.md), [локальная Kafka](docs/kafka-lab.md).

`make check` запускает тесты и проверку кода, `make build` собирает приложение. Проверены голосование в браузере, повторные ответы и восстановление после сбоев. [Подробности проверок](docs/branch-verification.md).

Цель проекта — 100 млн участников за минуту. Полный сайт на такой нагрузке ещё не проверен; результаты отдельных модулей описаны в [отчётах](docs/verification.md).
