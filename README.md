# Gigaquizz

Опросы на одну минуту. Вы создаёте вопрос и отправляете ссылку, участники выбирают ответ без регистрации, а после закрытия вы смотрите результаты в кабинете.

Можно выбрать один или несколько вариантов. Голосование длится ровно 60 секунд. При обычном повторном заходе из того же браузера учитывается первый сохранённый ответ.

Это ветка **simple-files**: сайт и хранение работают в одном Go-приложении, данные лежат в файлах. Версия с PostgreSQL и Kafka находится в [отдельной ветке](https://github.com/Unn0ne/gigaquizz/tree/postgres-kafka).

Для запуска на macOS или Linux нужны **Go 1.26.1+, Python 3 и make**:

```sh
git clone --branch simple-files https://github.com/Unn0ne/gigaquizz.git
cd gigaquizz
make dev
```

Откройте **http://127.0.0.1:8091/admin**. Пароль — строка `ADMIN_PASSWORD` в созданном файле `.env.simple-files`. В кабинете создайте опрос и скопируйте ссылку для участников. Остановить приложение можно через Ctrl+C.

Опросы и ответы сохраняются в `.local/files`. Этот каталог нужен для восстановления и резервной копии. Потеря единственного диска означает потерю данных.

`make check` запускает тесты и проверку кода, `make build` собирает приложение. [Настройки и другой адрес запуска](docs/launch.md), [как устроено хранение](docs/architecture.md), [что проверено тестами](docs/branch-verification.md).

Цель проекта — 100 млн участников за минуту. Файловый модуль уже прошёл отдельный тест со 100 млн записей; весь сайт на такой нагрузке ещё не проверен. [Результаты испытаний](docs/file-results.md).
