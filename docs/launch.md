# Запуск simple-files

Нужны Go 1.26.1+, Python 3 и make. Приложение использует стандартную библиотеку Go; базы данных и брокеры не запускаются.

```sh
git switch simple-files
make dev
```

При первом запуске создаётся `.env.simple-files` со случайным `ADMIN_PASSWORD`. Скрипт сохраняет существующий `.env.simple-files`. Для другого файла задайте `GIGAQUIZZ_ENV_FILE=/path/to/private.env`; обычный `.env` не меняется. Страница администратора — `${PUBLIC_URL}/admin`; по умолчанию http://127.0.0.1:8091/admin. Создайте вопрос, выберите время старта и поделитесь ссылкой на опрос. Для остановки — Ctrl+C.

| Переменная | Значение make dev | Назначение |
|---|---|---|
| `HTTP_ADDR` | `127.0.0.1:8091` | Адрес прослушивания |
| `PUBLIC_URL` | `http://127.0.0.1:8091` | Внешний origin для сайта и защиты запросов |
| `ADMIN_PASSWORD` | Обязателен, создаётся `make dev` | Пароль кабинета, минимум 16 символов |
| `DATA_DIR` | `.local/files` | Постоянный каталог опросов |
| `MAX_INFLIGHT` | `4096` | Максимум одновременных запросов голосования |
| `MAX_UNIQUE_VOTERS` | `120000000` | Предел точного пересчёта одного опроса |
| `FILE_BATCH_VOTES` | `4096` | Верхняя граница группы синхронизации |
| `FILE_QUEUE_VOTES` | `65536` | Верхняя граница очереди записей |
| `FILE_GROUP_LINGER` | `2ms` | Ожидание накопления группы |

Переменные внешнего окружения имеют приоритет над `.env.simple-files`. Старые `DATABASE_URL` и настройки Kafka для этой ветки не используются. Чтобы запустить рядом с другим экземпляром, задайте отдельные `HTTP_ADDR`, `PUBLIC_URL` и `DATA_DIR`.

```sh
make build
bin/gigaquizz -env /path/to/private.env
make check
```

Для внешнего HTTPS разместите приложение за обратным прокси и задайте правильный `PUBLIC_URL`. Приложение не пишет IP и токены голосующих в журналы запросов; настройки прокси и его access logs настраиваются отдельно.

Каталог данных должен находиться на локальном исправном носителе. Два writer одновременно не открываются. Перед переносом остановите приложение и скопируйте весь `DATA_DIR`, затем запустите ту же версию с новым путём. Смена ветки не конвертирует данные автоматически. Подробности — [архитектура](architecture.md).

Браузерные тесты создают настоящие опросы: используйте отдельный тестовый экземпляр, `npm ci` и `npx playwright install` (если Chrome/Chromium ещё не установлен), `E2E_BASE_URL` и `ADMIN_PASSWORD`, затем `make e2e`. Проверка занимает реальную минуту голосования; trace с токенами и паролями по умолчанию отключён.
