# QR-код для голосования

В кабинете выберите опрос и нажмите **«Показать QR-код»** рядом со ссылкой для участников. Код можно показать на экране или сохранить кнопкой **«Скачать PNG»** для презентации и печати. При выборе другого опроса старый код скрывается.

QR-код содержит ту же ссылку, которую копирует кнопка «Копировать». Сканирование открывает обычную страницу голосования. Разместить код можно заранее: участники дождутся начала опроса. Сам QR-код не истекает, но через минуту после старта опрос перестаёт принимать ответы.

Телефон должен иметь доступ к адресу в ссылке. `localhost` и `127.0.0.1` на телефоне означают сам телефон, поэтому для общего доступа откройте кабинет по публичному адресу сервиса или адресу в доступной участникам сети. `PUBLIC_URL` должен соответствовать этому адресу. Локальный запуск из README предназначен для проверки на одном компьютере.

При печати сохраняйте белую рамку вокруг кода и не растягивайте изображение непропорционально. PNG сохраняется с чёрными модулями на непрозрачном белом фоне.

Генерация происходит в браузере администратора. Код библиотеки поставляется вместе с приложением; запросов к стороннему генератору нет. QR-код не содержит пароля, административной сессии или идентификатора участника. Для обеих веток поведение одинаковое, на запись голосов эта функция не влияет.

[Источник и лицензия QR-библиотеки](../internal/web/static/qrcodegen.SOURCE.md). Для проверки используется независимый декодер: тесты считывают пиксели canvas и скачанного PNG и сравнивают полученную ссылку с выбранным опросом.
