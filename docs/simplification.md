# Упрощённая версия

Полный файловый сервис находится в ветке `simple-files`. Он включает HTTP API, сайт, кабинет администратора, постоянное хранение описаний/попыток/итогов и восстановление после перезапуска. PostgreSQL и Kafka из зависимостей этой ветки удалены.

[Архитектура](architecture.md), [запуск](launch.md), [различия веток](branches.md), [проверенные сценарии](branch-verification.md).

Исторические измерения пакетного файлового ядра — в [file-results.md](file-results.md). Их нагрузка 1,7 млн логических попыток/с не является измерением HTTP-производительности интегрированного сервиса. Подтверждение записи на единственный диск также не является гарантией при потере диска или узла.
