# Архив диалога Gigaquizz

- [dialogue.md](dialogue.md) — хронологическая запись для чтения.
- [messages.json](messages.json) — те же сообщения с ролями, временем UTC и фазами ответа.

Архив получен из локальной записи текущей сессии, начиная с первого запроса прочитать `go-poll-architecture-prompt.md`. Включены сообщения пользователя, публичные ответы и промежуточные обновления ассистента, а также показанные в интерфейсе вопросы. Используются только события интерфейса `UserMessage` и `AgentMessage` текущего диалога.

Служебные инструкции, внутренние рассуждения, переписка агентов и технические журналы инструментов в этот пользовательский диалог не входят. Исходная служебная запись сессии не копируется в репозиторий. Значения обнаруженных секретов заменяются на `[REDACTED_SECRET]`; число замен указано в JSON. Папки локальных баз, `.env` и клиентские ledgers нагрузочных тестов также остаются вне Git.

Содержимое сообщений сохраняется как история обсуждения: ранние решения и показатели могли измениться. Актуальные инструкции находятся в [launch.md](../launch.md), расчёт серверов — в [production.md](../production.md), последняя проверенная серия журнала — в [frame-results.md](../frame-results.md). Абсолютные локальные ссылки внутри сообщений сохранены в исходном виде; на другой машине открывайте соответствующие файлы относительно корня проекта.

Это снимок диалога на время `exported_at` в JSON. Сообщения, появившиеся после экспорта, требуют следующего обновления архива.
