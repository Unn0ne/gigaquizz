# Репетиция запуска генераторов на отдельных хостах

14 сентября 2026. Фактический стенд — один Mac M1 Pro, 10 логических CPU, 32 GiB RAM. Два процесса runner используют разные диапазоны одного опроса; отдельные физические хосты и 1,7 млн POST/с не проверены.

- `summary.json` — план, все исходы и уникальный итог двух минутных прогонов.
- `simple-files.json`, `postgres-kafka.json` — агрегаты настоящего HTTP, проверки часов, клиентских ledger, полный audit хранилища и восстановление после перезапуска.
- `checks.json` — Go/Python, Linux cross-build и отказ аудита при отсутствии одного диапазона.
- `provenance.json` — исходные коммиты, SHA-256 фактических исходников и бинарников. Бинарники собраны до коммита изменений; код задаётся хешами файлов, а не одним старым HEAD.

Опубликованы только агрегаты и хеши. Приватные планы, seeds, namespace, voter ID, пароли, адреса подключения и сырые ledger в Git не включены. `generation_complete` означает завершённую классификацию клиентских попыток; все попытки могут быть приняты только при соответствующем количестве ACK. Сохранность требует отдельного полного audit.
