# Проверка автономного комплекта

14 сентября 2026. Один Mac M1 Pro, 10 логических CPU, 32 GiB RAM. Для каждой ветки выполнен отдельный минутный опрос из комплекта вне checkout: 60 000 ID, 68 571 POST с повторами и 300 000 GET. Два runner подключались к адресу физического интерфейса той же машины. Это функциональный smoke, не измерение предельной нагрузки.

- `summary.json` — попытки, подтверждения, поздние отказы и уникальные итоги.
- `simple-files.json`, `postgres-kafka.json` — HTTP-агрегаты, проверки runner с лимитом родителя 16 FD, полный audit журнала и восстановление после restart.
- `checks.json` — финальные Go/Python-тесты, отрицательные проверки запуска, исключение приватных файлов из embed и исправленные ошибки тестовых сценариев.
- `provenance.json` — исходные коммиты, SHA-256 фактических исходников и полных проверочных комплектов. Сборки сделаны с явным dirty override до коммита. Исполнены macOS arm64; Linux amd64/arm64 только собраны.
- `clean-rebuild.json` — повторная сборка из чистых коммитов: все 12 бинарников совпали с проверочными побайтово; контрольные суммы комплекта проверены.

Всего сверено 137 140 подтверждений, потерянных или непроверенных подтверждений — 0. В Kafka-ветке две попытки отклонены после закрытия. Это не потеря подтверждённых голосов и не означает приём всех запланированных участников.

Публикуются только агрегаты и хеши. Сырые журналы, планы, seed, namespace, ID опросов и участников, пароли и адреса подключения остаются приватными. Исторические измерения из соседних каталогов не изменены.
